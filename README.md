# ¡Alta Nueva!

Juego web de navegador: Javier y Pablo, del área TIC de la AEI, corren por la oficina para dar la bienvenida a cada nueva usuaria antes que el otro.

- Elige a Javier o a Pablo; el otro lo lleva la máquina.
- Esquiva a los compañeros (te paran con incidencias), coge café para correr más y manda un ticket P1 a tu rival.
- Gana quien consiga 5 altas primero.

Controles: flechas o WASD. En móvil, arrastra el dedo sobre la oficina.

Todo el juego está en `index.html`, sin dependencias. Para jugar online, activa GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
